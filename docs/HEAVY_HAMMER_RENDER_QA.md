# Игровой QA-рендер тяжёлого молота

Стенд снимает основной framebuffer Minecraft. В кадре используются настоящий `PlayerRenderer`, сегментированная модель рук, `ItemInHandLayer`, текущая ресурсная модель, освещение мира и процедурная поза. Отдельного имитатора персонажа нет.

## Запуск игроком

1. Войти в мир и взять тяжёлый молот в основную руку.
2. Встать на открытом месте.
3. Нажать `F8`.
4. Не менять предмет до сообщения `[Hammer QA] Готово`.

Клиент последовательно фиксирует стойку, снятие веса, замах за спину, верхнюю точку, контакт, сопровождение и возврат. HUD временно скрывается, после завершения камера и прежнее состояние HUD восстанавливаются.

## Автоматический запрос

Запущенный клиент следит за файлом:

`%APPDATA%/.eclipse-rp/eclipse-debug/hammer-render/capture.request.json`

Скрипт создаёт запрос и ожидает завершения:

```powershell
python tools/request_hammer_render.py --mode full
```

Режим `idle` снимает только круг стойки, `full` — все ключевые фазы.

## Результат

Каждая сессия содержит:

- PNG настоящего игрового кадра;
- JSON с камерой, фазой, хватами, осями жёсткого тела, коллизиями и ограничениями IK;
- копию фактического `live-pose.json`;
- `session.json` с состоянием захвата.

После завершения контактный лист собирается командой:

```powershell
python tools/inspect_hammer_render.py
```

Шлях останньої сесії завжди записаний у `hammer-render/latest.json`.
