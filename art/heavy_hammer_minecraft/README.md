# Тяжёлый рабочий молот Minecraft

Недорогой ремонтопригодный средневековый инструмент: грубое кованое железо, ясеневое древко, простая обмотка, четыре защитные полосы и видимые клинья. Без бронзы, геральдики и декоративной кожи.

Модель предмета и пиксельный атлас 128 px копируются в ресурсы клиента Eclipse. glTF-источник содержит жёсткие узлы хватов, точки контакта и четыре клипа.
